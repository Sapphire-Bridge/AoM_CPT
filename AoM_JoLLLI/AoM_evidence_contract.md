# JoLLI Evidence Contract (AoM)

This file is the canonical evidence table for the JoLLI AoM paper.

**Rule:** every empirical sentence in the manuscript should cite one or more Evidence IDs from this table.

Evidence ID namespaces:
- `E#`: empirical result claims backed by **canonical run artifacts** (CSVs/JSONs) produced by `bash scripts/run_submission_full_strong.sh` (default output dir: `results_submission_full/`), unless a row's Notes specify a different runner script.
- `R#`: run provenance / integrity facts backed by the same run’s manifests (`results_submission_full/*.manifest.json` + `results_submission_full/RUN_MANIFEST.json`).
- `C#`: implementation guarantees backed by code in this repo (what the pipeline does, not what any particular run did).

Conventions:
- **CI** is one of: `✓` (present for the primary metric), `varies` (present in some listed artifacts), `–` (not applicable / not reported).
- **Controls** lists run-time control conditions reported in the artifact (avoid mixing code-claims into `E#` rows).
- **Bootstrap unit** is the resampling unit used for the reported CIs (when applicable).
- **Artifact(s)** are repo-relative paths in this workspace (for the canonical run output directory noted above).
