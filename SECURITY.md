# Security Policy

## Reporting a Vulnerability

Please report security issues privately by email:

- `felix.borck@gmail.com`

Include:

- affected file(s) and command path
- impact summary
- reproduction steps
- suggested mitigation (if available)

Please do not open public issues for unpatched vulnerabilities.

## Scope Notes

This repository executes model-loading and evaluation workflows and may run third-party model code when explicitly enabled. By default, `--trust_remote_code` is disabled.
